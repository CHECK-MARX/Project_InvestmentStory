PDF出力用の Noto Sans JP Regular を組み込みます。`NotoSansJP-Regular.ttf` は
開発環境に導入されていた `NotoSansJP-VF.ttf` の weight=400 を
`fontTools.varLib.instancer` で固定化したものです。
元フォントは SIL Open Font License 1.1 で、同梱の `OFL.txt` を参照してください。
生成手順は `artifacts/monthly_report_20261024/prepare_font.py` にあります。
